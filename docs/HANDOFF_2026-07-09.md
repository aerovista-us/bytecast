## Executive summary

ByteCast’s **Golden Path onboarding spine was replaced** with a four-day agent orientation sequence that teaches operating law before app inventory. Legacy Day 1 episodes (EP-001–004) remain as optional reference; they are **no longer required** for badge `p1_golden_path_v1`.

**Narration forge** is wired for all four agent days via NXCore EchoVerse TTS (port **5315**). **Agent Day 1 audio is forged and verified on nxcore** (9 WAV segments + manifest). Days 2–4 have forge configs and npm scripts but **audio has not been forged yet** — players fall back to browser listen mode until forge is run.

A cross-lane **training upgrade** pass enriched profiles, fixed mojibake, and added overlay-driven metadata tooling (`npm run upgrade:trainings`).

### 5. NXCore TTS troubleshooting (resolved)

| Issue | Cause | Fix |
|-------|--------|-----|
| `:NXCORE_TTS_URL: command not found` | PowerShell `$env:` syntax in bash | Use `export NXCORE_TTS_URL="http://127.0.0.1:5315/api/generate"` |
| TTS 404 at `:8787` | Wrong default port | Point to **5315** |
| HTTP 400 “Only wav is supported” | Forge requested `format: "mp3"` | Switched to `wav` in voice recipes + forge-lib defaults |

**Working nxcore commands:**

cd /srv/Collab/mini.shops/bytecast
