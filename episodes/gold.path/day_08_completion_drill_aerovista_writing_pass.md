# Agent Day 8 Completion Drill — AeroVista Writing Pass

Complete this after listening to “Writing Like AeroVista.”

Use a real or simulated AeroVista writing task.

## 1. Writing Type

Choose one:

- AVCC brief
- Handoff
- EOD Capsule
- Client update
- Builder support response
- Public copy
- Proposal section
- Release note
- ByteCast script
- Queue card
- Legal/compliance note
- Technical documentation
- Other

## 2. Audience

Who is the reader?

Choose one:

- Founder / CEO
- Operator
- Builder / Creator
- Client
- Prospect
- Public visitor
- Employee
- Contractor
- Agent
- Technical maintainer
- Legal reviewer
- Shareholder
- Mixed audience

## 3. Purpose

What should this writing accomplish?

Examples:

- Inform
- Decide
- Train
- Sell
- Warn
- Handoff
- Request approval
- Summarize status
- Reduce risk
- Explain next step
- Document evidence

## 4. Current State

Choose one:

- Planned
- Drafted
- Built
- Live
- Healthy
- Released
- Adopted
- Blocked
- Stale
- Unknown
- Conflicting

## 5. Evidence

List the evidence supporting the writing.

Label each source:

- Live system
- Registry
- Release board
- Handoff
- EOD Capsule
- Documentation
- Memory/context
- Operator instruction
- Legal/compliance source
- Test result
- External source

## 6. Boundary Check

What must not be exposed?

Examples:

- Secrets
- Credentials
- Internal logs
- Private emails
- Client data
- Builder data
- Internal URLs
- Security details
- Proprietary methods
- Unreleased strategy
- Legal terms not approved for public use
- Raw memory content

## 7. Bloated Draft

Write a deliberately rough or bloated version.

## 8. AeroVista Rewrite

Rewrite it using the AeroVista standard:

- Clear
- Useful
- Evidence-based
- Audience-aware
- Safe to share with the intended reader
- Specific about state
- Honest about uncertainty
- Ends with a next action

## 9. Truth Labels

Mark each major claim in the rewrite:

- Verified
- Reported
- Inferred
- Unknown
- Conflicting

## 10. Anti-Bloat Check

Answer yes/no:

Did I lead with the point?  
Did I remove empty hype?  
Did I separate fact from recommendation?  
Did I name the current state?  
Did I include evidence or confidence where needed?  
Did I protect sensitive details?  
Did I write for the actual audience?  
Did I end with a next action?

## 11. Final Version

Write the final version in 10 sentences or fewer.

## 12. One-Line Rule

Write one sentence that captures the rule you followed.

Example:

“I wrote for the operator, not for the mythology.”
