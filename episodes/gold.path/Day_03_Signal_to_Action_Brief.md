# Agent Day 3 Completion Drill — Signal-to-Action Brief

Complete this after listening to “From Signal to Action.”

Choose one real or simulated AeroVista signal and convert it into an AVCC-style brief.

## 1. Signal
What changed?

## 2. Context
Which division, system, release, client, builder, route, document, or workflow does this affect?

## 3. Why It Matters
What is the operational consequence?

## 4. Recommended Action
What should happen next?

Use a clear action verb:
- Verify
- Update
- Escalate
- Block
- Approve
- Deploy
- Roll back
- Assign
- Archive
- Document
- Notify
- Test
- Close
- Move to P2/P3

## 5. Why Now
Why does this action matter at this moment?

## 6. Expected Impact
What improves if this action is taken?

## 7. Risk If Ignored
What happens if nobody acts?

## 8. Priority
Choose one:

P1 — Critical  
P2 — High  
P3 — Standard

Explain why.

## 9. Confidence
Choose one:

High  
Medium  
Low  
Unknown

Explain what evidence supports the confidence level.

## 10. Evidence
List the evidence used.

Label each source:
- Live system
- Registry
- Release board
- Handoff
- EOD Capsule
- Documentation
- Memory/context
- Operator instruction
- Legal/compliance source
- External source

## 11. Owner or Lane
Who should own the next move?

Examples:
- AVCC
- Nexus TechWorks
- EchoVerse
- Art Localized operator
- Lumina
- Vespera
- Summit
- Horizon
- SkyForge
- AeroVista HQ
- Legal/Compliance
- Founder/CEO

## 12. Memory / Handoff Update
Should this be written back into memory, release notes, EOD Capsule, handoff, registry, or documentation?

## 13. Final AVCC Brief
Write the final version in 8 sentences or fewer.
