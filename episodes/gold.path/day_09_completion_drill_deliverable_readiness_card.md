# Agent Day 9 Completion Drill — Deliverable Readiness Card

Complete this after listening to “From Draft to Deliverable.”

Use a real or simulated AeroVista deliverable.

## 1. Deliverable Name

Name the deliverable clearly.

## 2. Current Delivery State

Choose one:

- Drafted
- Ready for Review
- Revision Needed
- Ready for Delivery
- Delivered
- Verified
- Adopted
- Unknown

Explain why.

## 3. Purpose

Why does this deliverable exist?

## 4. Audience

Who will use or review it?

Choose one:

- Founder / CEO
- Operator
- Builder / Creator
- Client
- Prospect
- Public visitor
- Employee
- Contractor
- Agent
- Technical maintainer
- Legal reviewer
- Shareholder
- Mixed audience

## 5. Output

What exactly should exist when this slice is done?

Examples:

- Script
- Drill
- HTML page
- ZIP pack
- Handoff
- Email
- Proposal section
- Release note
- Registry update
- Audio file
- Checklist
- Dashboard card
- Smoke result

## 6. Acceptance Criteria

List the required criteria.

At minimum, include:

- Required sections or features
- Required format
- Required safety/boundary check
- Required evidence or verification
- Required next action or handoff

## 7. Out of Scope

What is intentionally not included in this slice?

## 8. Polish Ladder Check

Answer yes/no:

Correct:  
Complete:  
Clear:  
Safe:  
Useful:  
On-brand:  
Beautiful enough for this stage:

## 9. Evidence

What proves the deliverable is ready?

Label each source:

- Live check
- Registry
- Release board
- Documentation
- Handoff
- EOD Capsule
- Memory/context
- Operator instruction
- Legal/compliance source
- Test result
- Reviewer approval

## 10. Scope Creep Check

List any good ideas that appeared but should become next-slice items instead of blocking this slice.

## 11. Risk If Delivered Too Early

What could break if this ships before acceptance criteria are met?

## 12. Risk If Delayed Too Long

What value is lost if this keeps expanding instead of shipping?

## 13. Boundary Check

What sensitive information must be removed, summarized, restricted, or escalated?

## 14. Required Updates

Check all that apply:

- EOD Capsule
- Handoff doc
- Release board
- Registry
- Documentation
- Memory
- Backlog/task board
- Git commit/release notes
- Legal/compliance review
- Client approval
- No update needed

## 15. Final Delivery Decision

Choose one:

- Keep drafting
- Send to review
- Revise before delivery
- Ready for delivery
- Deliver now
- Verify after delivery
- Escalate before delivery

Explain in 3 sentences or fewer.

## 16. Final Handoff Line

Write one sentence the next agent should see before touching this work.
